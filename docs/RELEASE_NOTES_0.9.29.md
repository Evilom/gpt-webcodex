# 超级智囊团 0.9.29

修正 ChatGPT 原生网页显示“消息流中的错误”时，工作台仍可能显示正常的问题。

- 识别当前轮次可见的中英文消息流错误，并记录独立的网页错误事件。
- 忽略旧轮次残留的错误和正文、代码中的错误示例，避免影响后续生成状态。
- 提醒网页“重试”可能重新生成并再次调用工具，应先核对已完成步骤再在原会话续接。
- 这类错误不再提供默认刷新操作；网页错误不会将仍在运行的本地命令标成失败。

观察器不自动点击重试、不自动重新发送消息，也不重启健康的 MCP 服务。本版修正错误识别与恢复提示，不承诺恢复已经失败的上游生成流。

已验证隔离 Electron 中的原生错误提示、旧轮次错误隔离、正文／代码误报防护，以及没有自动点击重试的副作用。
