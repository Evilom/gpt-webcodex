# 超级智囊团 0.9.32

包含 0.9.31 的目标模式与网页错误识别，并修复真实更新检测中发现的 Mac 兼容问题。

- GitHub API 限流时，Electron 的网页请求可能不提供重定向后的 `Response.url`；此前 Mac 更新检查会报 `Invalid URL`。现在从我们公开 Release 页的头部元数据确认版本，继续严格校验仓库地址和稳定版本，避免依赖空 URL。
- 顶部“目标”可按会话开启，默认关闭；回复结束后核对已有文件和验证记录，再推进剩余步骤。明确消息流异常仅在本地执行空闲、连接正常时有限退避接续。
- 保留草稿、附件、正在输入的内容与网页权限确认；手动停止、导航、工作区切换、重启或发送结果不明时暂停。不会自动点击网页“重试”、停止生成或刷新。
- `Invalid conversation body` 单独提示为对话请求内容无效，并暂停目标模式；填写续接消息期间出现错误也会取消发送。
- 每个标签独立保存目标，后台目标计入安装更新和登录会话清理的忙碌检查。模型报告完成仍需查看原会话的交付与验证结果。

真实公开更新入口已验证限流与 Electron 空 URL 场景；目标模式还经过安装包内实际代码、隔离浏览器和本地 HTTP 传输验证，不使用生产登录或调用 Pro。此版本不承诺修复 ChatGPT 上游所有消息流或无效对话请求。

Windows 可在应用内检查、下载和安装更新。Apple Silicon Mac 可检测新版并打开发布页，下载 DMG 后替换应用；旧版若检查失败，可直接通过本 Release 或 SMB 安装本版。保留各设备原有配置、登录、工作区和通道，不复制其他设备的密钥。
