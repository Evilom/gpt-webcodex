# 超级智囊团 0.9.22

- 修复实际运行中抓到的上下文检索积压：多个准备请求重复创建搜索线程池，远端响应超时后仍继续扫描。现在同一 Runtime 共享最多四个搜索工作线程，一次上下文准备的搜索共享十秒预算。
- `rg` 搜索超时会保留部分结果并明确标记不完整，不再重新进入整目录的 Python 扫描。Python 上下文后备搜索会在时间或匹配数量预算到达时停止；超过 2 MiB 的文件留给明确的文件读取请求。
- Python 后备搜索先检查二进制文件头，不再为了排除二进制文件先把整个文件读入内存。
- 包含已验证的连接修复：优先使用 Tunnel 实际控制面健康结果；诊断修复按故障层处理；HTTP 响应中途断开后及时结束等待，避免请求和心跳悬挂。

0.9.21 的发布已取消，本版统一交付上述修复。不更改登录、工作区、端口、代理节点、Tunnel ID 或密钥。明确点击“重启服务”仍会重启全部服务；更新需在当前任务允许退出时安装。
