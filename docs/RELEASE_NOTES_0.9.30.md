# 超级智囊团 0.9.30

增加原生多标签，减少多个长对话来回切换时替换正在生成的网页。

- 每个标签保留独立 WebContents、消息流观察器、草稿、附件选择和导航历史；切换标签不重载、不重复发送消息。
- 当前页面加载、生成或恢复连接时，点击其他对话先询问是否在新标签打开，默认保留当前页。同一对话优先切到已有标签；Ctrl/Cmd 点击或中键点击对话链接可以直接新开。
- 后台标签继续接收流，单独提示生成、完成或异常。关闭进行中的标签需要确认，更新检查会同时保护后台标签。
- 最多保留 8 个标签，避免无限增加内存占用；支持新建、关闭、Ctrl/Cmd+T、Ctrl/Cmd+W、Ctrl+Tab 和方向键切换。
- 登录会话、代理和本地 MCP 工作区继续共享；新增标签不重新设置代理或重复注册下载处理。不会自动关闭或丢弃后台标签。

标签保留到软件退出；没有持久化未发送草稿的承诺。标签隔离不能修复 ChatGPT 上游已经失败的生成流，也不保证多个对话并行修改同一工作区文件的安全。

隔离 Electron 中使用真实 HTTP/SSE 传输与原生网页容器验证双流并行、60 次切换、草稿与附件保留、真实文件下载、背景异常隔离以及实际 preload/IPC 标签切换。测试不使用生产登录，不调用模型。
