# 超级智囊团 0.9.24

- 自动记忆从末尾查找最新一组问答，不再逐轮复制历史 DOM；代码块、工具输出、按钮和 SVG 子树直接跳过。单条消息最多遍历 4096 个节点，原始文字读取也有固定预算，保留用户 6000 字符、助手 8000 字符的输出上限。
- 保留记忆稳定性等待与去重；生成中的中文停止按钮也会阻止提前抓取，侧栏变化不触发重新扫描，正文容器替换后继续观察。
- 断流检测仅依据页面真实状态提示，避免回答中讨论或引用“连接已中断，正在等待完整答复”时误报连接异常；限制每次检查的提示数量与文字量，不再读取整条回复。
- 将真实 Chromium 中的长对话、超长文字、复杂 DOM、中文停止按钮、去重和引用错误文案检查加入发行验证。

自动记忆仍只读取页面，不修改对话、输入框或项目文件。包含 0.9.23 的状态隔离与请求关联日志；更新不改变登录、工作区、端口、代理、Tunnel 和密钥。进行中的任务结束后再安装。
