# v0.9.7

长会话的页面监听改为合并处理，已识别的 MCP 历史不再重复扫描，重复网络错误按 30 秒限频写入日志。资源诊断增加 ChatGPT 静态资源和附件域名。

主页面加载超过 60 秒会结束等待；首页瞬时错误最多退避重试 5 次。具体聊天和 OAuth 回调不会自动重载。无响应或崩溃时可点击“恢复页面”，本地 MCP 任务继续运行。

关闭时移除页面事件、定时器并跳过 beforeunload，清理最多等待 8 秒；异常和堆栈写入本地日志。退出助手保留后台服务的行为保持不变。

启动 15 秒后自动检查 Evilom/gpt-webcodex 的正式 Release，运行期间每 6 小时再次检查。设置和托盘可以手动检查；Windows 用户选择下载并在任务结束后安装，不会自动退出。下载由 electron-updater 校验 Release 的 SHA-512。Apple Silicon 版本显示新版并跳转下载，仍需手动安装。

官方 OpenAI Tunnel Client 更新到 0.0.16；保留用户现有 Tunnel、代理、工作区和登录配置。合入 Coding Tools 上游固定 Windows 进程清理路径的修复。

Windows 与 Mac 安装包均未使用商业代码签名证书；Mac 包为 ad-hoc 签名，未 notarize。

原仓库截至本次核对仍为 2402d18，已包含于本版本。参考 Chat on Steroids 的有界退出、重复处理抑制和自有 Release 更新流程，按本工程实现。

代理/VPN 节点、ChatGPT 服务端或账号状态导致的连接故障仍可能发生。本版本改善等待、诊断和恢复，不保证外部链路永不中断。

Windows 构建及任务恢复校验统一使用 UTF-8 输出，修复 CI 中文输出编码导致的构建中断。v0.9.6 未发布 Release。
