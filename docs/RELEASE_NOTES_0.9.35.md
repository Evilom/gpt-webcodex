# 超级智囊团 0.9.35

包含 MCP 2026-07-28 协议兼容和仓库索引读写优化，并修复阻断 0.9.34 Mac 发行的后台任务测试时序竞争。

- 支持 OpenAI tunnel-client 0.0.16 通过 `params._meta` 声明新协议，直接执行 `server/discover`、`tools/list` 和 `tools/call`；校验请求镜像头，补齐现代响应字段，保留旧版握手与桌面内部 discovery。
- 保留路径到 FTS rowid 的索引映射、每 128 项分批提交、300 秒索引过期阈值与各工作区的后台索引策略。
- 后台交接测试改用线程同步信号控制完成顺序，避免 CI 调度延迟导致模拟任务提前结束、错误读取交接响应。任务已完成时直接返回最终结果的行为保持不变。
- Windows 便携 Python 安装依赖时禁用字节码编译；发行资源统一排除 `__pycache__` 和 `.pyc`，并校验包内协议源码与发行源码一致。
- 桌面与 Runtime 版本同步为 0.9.35；公共工具 Schema 仍为 v16、12 个工具。保留已推送的 `v0.9.34` 标签。

已用真实 `tunnel-client dev proxy` 验证新协议 discovery、工具列表和工具调用，并确认旧握手仍可用。真实 ChatGPT 网页与 OpenAI 线上通道的验收需要更新安装后在原使用环境中完成。
