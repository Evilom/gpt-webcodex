# 超级智囊团 0.9.27

智囊工作台不再把配置、模型回复和所有生图历史排成一条长列表。

- 增加“模型辅助 / 异步生图”切换，设置默认收起；模型回复一次展开一份。
- 生图任务每页 5 条，可筛选全部、进行中与待确认、历史任务。分页可以访问全部历史，不再受最近 30 / 50 条的显示限制。
- 支持列表与缩略图宫格切换，记住浏览方式；宫格两列、每页 4 张，仅加载本页小预览，最多同时读取 2 张。
- 点选任务进入独立详情，返回保留页码；只按需读取小预览，可打开和另存本地原图。
- 查询详情始终关联原任务编号，任务完成或排序变化后也能继续查看；隐藏的辅助视图停止定时轮询。

保留原生 ChatGPT 对话、本机服务、模型选择与生图开关。没有新增生成请求、自动重试或账户凭证迁移。

已用本机既有生图任务验证分页、筛选、详情、三种主题与原图保存；另有超过 50 条历史及任务状态变化的回归验证。
