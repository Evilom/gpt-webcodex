# 超级智囊团 0.9.31

增加按会话开启的目标模式，完善原生 ChatGPT 错误识别。

- 顶部“目标”入口可填写目标与最多接续轮数，默认关闭；每个标签独立保存目标。回复稳定结束后，先核对已有文件和验证记录，再推进未完成步骤。
- 对明确的消息流错误采取有限次数的退避接续，发送前确认本地命令、后台操作均空闲且 MCP / Tunnel 正常。不会自动点击原生“重试”、停止生成或刷新网页。
- 保留未发送草稿、附件和正在进行的输入；网页权限与对话框等待用户处理。手动停止、导航、工作区切换、重启和发送结果无法确认时暂停，避免重复执行。
- 单独识别 `Invalid conversation body`，显示“对话请求内容无效”并暂停目标模式；填写续接消息期间出现该错误也会取消发送、保留草稿。
- 模型明确报告目标完成后停止接续，界面标记“模型报告完成”；需要授权、缺少关键条件或达到轮数上限时暂停。
- 后台目标纳入更新安装和共享登录会话清理的忙碌检查，保护进行中的对话。

验证包含隔离 Electron 原生网页容器、真实本地 HTTP 传输、多标签、草稿与权限保留、发送确认，以及本次截图错误的浏览器回放。测试不使用生产登录或调用 Pro。此版本不承诺修复 ChatGPT 上游所有消息流或无效对话请求；请保留已有成果并查看错误提示，避免连续点击重试。

Windows 使用应用内“检查更新”下载后安装；Apple Silicon Mac 可检测新版并打开发布页，下载 DMG 后替换应用。配置和登录资料保存在原用户目录，安装包不包含密钥。
