# 超级智囊团 0.9.17

工作空间采用可收起、可调整宽度的导航与工作台，统一浅色、深灰和纯黑主题，补齐面板切换与任务反馈动效。更多菜单和历史改为独立浮层，打开时不再挤压 ChatGPT 页面；窄窗口按可用宽度收起侧栏。

新增默认关闭的「独立对话渲染（实验）」，复用 MIT 授权的 assistant-ui Claude 示例和消息、Markdown、复制、滚动组件。保留原生 ChatGPT 会话，实验界面显示网页已加载的消息，支持表格、代码与公式，并可直接输入、发送、停止生成、上传附件与下载文件。

草稿与原网页双向同步，附件交给原网页上传，下载沿用工作区保存及校验流程。中文输入法组合期间不会发送；附件未就绪时不能发送；重复点击合并为一次操作。选文件期间切换会话会取消添加。草稿冲突保留双方内容，未确认的输入仅在内存中保存供恢复；网页未响应或操作未确认时不会自动重发。工具详情、历史分支与编辑仍可返回原网页处理。

实验功能不增加模型 API 请求，不自动抓取完整历史，也不把会话另存或发送给辅助服务。页面结构不匹配、登录验证或渲染失败时保留原网页；默认模式继续使用原生对话。包含开源组件、KaTeX 字体许可证及来源说明。

Windows 安装包及 Apple 芯片 Mac 安装包由本仓库发行流程生成。更新需重启应用才能生效，请在当前网页回答与本地任务结束后安装。

发行回归显式验证普通动效与系统减少动效两条路径，避免不同系统偏好导致误判。0.9.16 未发布安装包，0.9.17 为本轮正式发行版本。
