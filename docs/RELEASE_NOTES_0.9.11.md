# 超级智囊团 0.9.11

网页 MCP 助手更名为“超级智囊团”，采用简洁顶栏、可收起的工作台和分层连接异常提示，保留已有登录、工作区、通道和密钥。

太极与 AntiGravity 的扩展辅助现由主 AI 通过 `consult_advisors` MCP 工具按需发起。工作台只设置允许调用的 Opus / Gemini 等模型并显示进度和结果，移除人工提问入口。主 AI 提交必要材料、查询原任务并复核辅助意见。

输入校验覆盖问题字符数、材料数量和服务端动态 UTF-8 字节预算（含提示模板）。咨询异步执行，提交立即返回持久化任务 ID；超时或断线后查询原 ID，不自动重发、截断材料或切换模型。辅助失败不会把健康的本地任务标为失败，服务密钥继续由桌面主进程加密保存。

包含此前的网页附件下载、连接中断识别、页面恢复及退出稳定性修复。自动更新继续使用 Evilom/gpt-webcodex 的 Release。

MCP Schema 更新为 v15，公开工具共 11 个。升级前的聊天如果未识别新增工具，可新建聊天刷新工具定义。

提供 Windows 安装包和 Apple Silicon Mac 的 DMG / ZIP。构建流程覆盖界面、MCP 回归、异步咨询链路、下载及安装包检查。Mac 验收使用独立配置目录，不触碰正常使用的登录资料。
