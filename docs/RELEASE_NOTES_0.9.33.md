# 超级智囊团 0.9.33

将 Mac 0.9.28 安装包的临时索引修复合入正式源码，避免升级后回退。保留 0.9.32 的目标模式、多标签及更新检测修复。

- 新增路径到 FTS rowid 的 B-tree 映射，更新、删除文件时按 rowid 定位，避免扫描 `path UNINDEXED` 的整张全文表。首次迁移保留旧 rowid 和内容，创建映射与回填采用同一事务，失败可重试。
- 每 128 项新增、更新或删除提交一批，缩短写事务；批次提交后若进程中断，下次刷新会核对已落盘记录，避免留下清单未记录的孤立文件。分批提交不承诺 WAL 固定大小。
- 上下文请求触发后台刷新的过期阈值从 30 秒改为 300 秒。这是按请求检查的条件，不是固定每五分钟扫描。
- 遵守每个工作区 `.coding-tools/index-policy.json` 中的 `background_enabled`。关闭的工作区返回 `index_status=disabled`，不打开聚合索引、不启动新刷新；独立项目的策略保持独立。安装升级不覆盖工作区策略或索引数据。
- 以真实仓库文件副本和基于真实源码内容的 6000 行 SQL 负载验证索引性能；新增增删改、旧索引迁移、迁移中断、批次中断、批量删除、后台开关和刷新阈值回归测试。

若工作区是所有项目的容器目录，可在该根目录创建 `.coding-tools/index-policy.json`：

```json
{"background_enabled": false}
```

此设置阻止新的自动索引刷新；已开始的刷新不会被强制中断。已有索引不删除或重置，读取、搜索和编辑工具继续可用。要索引单个项目，请切换到该项目工作区；策略不从父目录继承。没有增加默认关闭所有项目索引的全局策略。

性能结果来自隔离副本、单次暖缓存测量，不代表整机物理读盘或长期负载。发布过程不会重启现有 Mac 服务，也不会改动现场补丁、索引备份、代理或其他服务。
