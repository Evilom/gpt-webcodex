# 超级智囊团 0.9.26

- 工作台扩展辅助增加“允许 AI 后台生图”开关，复用已部署的本机 CLIProxy 异步入口；导入 integration.json 后可启用，无需导入账户凭证。
- 新增 image_jobs 工具：查询配置、提交、查询结果、任务列表和显式小预览。提交快速返回任务编号，主 AI 可继续独立工作，不循环等待出图。
- 稳定编号去重并持久化；提交状态不确定时保留编号，不自动重新生成。关闭开关只影响后续提交，独立生成进程继续运行。
- 支持查看排队、生成、完成、失败或待确认状态；任务卡默认折叠，展开才加载小预览，可打开、另存原图，保留已有审核标记。
- 侧栏隐藏时停止进度刷新，空闲时仅检查轻量状态；原图不自动回传 Pro，生成成功与内容审核分开记录。
- MCP Schema 升至 v16，12 个公开工具；Runtime 与桌面版本同步。保留 0.9.25 的页面恢复修复。

本功能需要每台设备先部署本机 CLIProxy、Python 和异步任务入口，不包含 CLIProxy 的安装与账户授权。软件保留上游实际返回的尺寸，不自动裁切或缩放原图。安装更新前请完成当前网页任务；已有后台生图进程由独立入口管理。
